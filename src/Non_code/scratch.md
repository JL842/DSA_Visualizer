## Requirements Specification


From the program goal I have set out I have defined what it should contain:

**Main Menu** - As a developer, I want to make the introduction clear and easy when opening the app, therefore a main 
menu should be the first thing to be shown on the app and all the options.

**Pages** - As a developer, I want to make my architecture scalable and complex as it needs to be, therefore I would need
a page class, so each page is similar and consistent for myself on keeping a clean structure on creating each algorithm
/ data structure and the user for familiarity of the structure.

**Display** - As a developer, I want a selected of defined ways to display each algorithm when it starts, therefore 
different visualising structures using JavaFX should be utilised and similar DSA's can share for easiser and consisten
design in the long run if possible.


**Animation** - As the front end developer, I want to show appealing animation when the algorithm starts not only to 
make it clearer for the user of what is going on at one time in the process but also achieves the objective of the app
which should deepen the understanding of how the algorithm operates.

**Custom config** As a developer, I want the user to be able to customise the there experience when understanding their 
chosen algorithm to understand, therefore the speed of the algorithm at their desired choice, the option to switch pages
and the option to pause and switch with user input or randomise data.
