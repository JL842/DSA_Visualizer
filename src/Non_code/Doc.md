
# Data Structure and Algorithm Visualizer

---

### Author - Jasper Lodge (jal140)
### Created - 02/02/2026

---

- An app to visualise on how an algorithm or a data structure works because as a learner I always find it easier
  to understand topics if I can visualise or visually see how it works, so I thought this would be a good and
  relevant Java project.


- I will use JavaFX for the UI framework to be the interface of the program. At this time I will only implement
  Algorithms and structures that I have been taught but possibly will do new or advanced Algorithms if I can
  successfully get the base of the project down.
